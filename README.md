# 📊 Supply Chain Analytics Dashboard | Power BI

An interactive Supply Chain Analytics Dashboard built using **Power BI**, **DAX**, and **Power Query** to analyze sales performance, profitability, customer behavior, and geographic trends. The dashboard provides actionable business insights through interactive visualizations and KPIs.

---

## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution for supply chain data. It transforms raw transactional data into meaningful insights using data modeling, DAX measures, and interactive dashboards.

The dashboard enables users to:
- Monitor business KPIs
- Analyze sales and profit trends
- Identify top-performing markets and products
- Explore geographic sales distribution
- Support data-driven business decisions

---

## 🎯 Business Objectives

- Analyze sales and profit performance
- Track monthly business trends
- Identify high-performing markets and regions
- Understand customer purchasing behavior
- Visualize sales geographically
- Improve decision-making through interactive reporting
